# AI 漫剧管线

把「剧本 → 分镜 → 出图 → 出视频 → 配音 → 配乐 → 剪辑」做成一条可插拔、
可回溯、可审计的自动化生产管线。

---

## 快速开始

```bash
# 1. 安装（会自动建虚拟环境、装依赖）
python 安装.py

# 2. 配置 API Key
cp .env.example .env
# 编辑 .env，填入 ARK_API_KEY / VOLC_TTS_TOKEN / LLM_API_KEY

# 3. 启动
python 启动.py
```

浏览器打开 <http://127.0.0.1:8501>

## 能力一览

| 环节 | 默认实现 | 备选 |
|---|---|---|
| **写剧本** | DeepSeek | 豆包 / Kimi / 通义 / GLM |
| **出图** | 火山方舟 Seedream 5.5 | 本地 ComfyUI / SD WebUI / SDXL |
| **出视频** | 火山方舟 Seedance 2.5-flash | 可灵 / 即梦 / 本地 Blender |
| **配音** | 豆包语音合成 2.0 | Edge-TTS（免费） |
| **配乐** | 合成音 | 曲库 / 静音 |
| **剪辑** | ffmpeg（节奏剪辑） | 自动剪辑 / 手动 / 打包 |
| **3D 场景** | Blender | 占位 |
| **电台** | TTS + ffmpeg | 手动 |

**共 9 类能力、47 个插件实现。**

## 主要特性

**架构**
- 插件化 Provider 抽象，换供应商不改业务代码
- 多阶段流水线，阶段/项目/任务三层进度模型
- 断点续跑与幂等重入

**可靠性**
- 跨进程状态同步（文件锁 + 原子替换），解决 CLI/Web 双进程写入丢失
- LLM 输出三级回落解析（直接解析 → 截取 JSON → 括号栈修复）
- 产物完整性校验，不合格进人工待办队列

**可回溯**
- 文件级版本快照、镜头变体管理
- 回收站（7 天保留）
- 回滚六重校验 + 四种策略（阻断/等待/取消/强制）

**安全**
- PBKDF2-SHA256 密码、HMAC 会话、RBAC（4 角色 27 权限）
- 18 类破坏性操作二次确认（一次性令牌 + 参数哈希绑定）

**成本**
- 三层记账 + 预算告警
- SQLite 用量库记录每次调用的 token/图数/秒数/金额

**质量**
- 24 个测试脚本覆盖 123 个接口
- 一致性检查、剧情状态继承

## 技术栈

- **后端**：Python 3.11+ / FastAPI / 多线程 / 文件锁
- **前端**：原生 JS 单页应用（无框架）
- **存储**：SQLite（用量库，WAL）/ JSON（状态）
- **媒体**：ffmpeg / Pillow
- **AI**：火山方舟 / DeepSeek / 豆包语音 / ComfyUI
